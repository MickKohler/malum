Exercise Sheet 3

Sequences, limits and functions

Exercise 1 (Limits) 2 + 2 + 2 points

Determine the limits of the following sequences $(x_n)_{n \in \mathbb{N}}$ using suitable estimates.

  1. a) $x_n = \dfrac{\sin(n) + \cos(n)}{n}$
  2. b) $x_n = \dfrac{n^n}{2^{(n^2)}}$
  3. c) $x_n = \sqrt{n^2 + n} - n$

Exercise 2 (Functions) 3 + 3 points

Let $f \colon \mathbb{R} \to \mathbb{R}$ be given by $f(x) = x^2 \sin(x)$.

  1. a) Sketch $f$ on the interval $[-2\pi, 2\pi]$ and describe its behaviour.
  2. b) Compute $f'(x)$ and determine all critical points in $[0, \pi]$.

Exercise 3 (Accumulation points) 4 points

Show that $c \in \mathbb{R}$ is an accumulation point of $(x_n)$ if and only if for every $\varepsilon > 0$ there are infinitely many $n \in \mathbb{N}$ with $|x_n - c| < \varepsilon$.
